# Contributing to NVL Forms

Changes must remain headless, consumer-neutral, and installable without `nvl/activity`.

Add Pest coverage for definitions, translations, pre-validation authorization, UUID/handle routes, origins, real CORS preflights, throttling, tokens, spam, registration and idempotency races, callback isolation, privacy, and sanitized after-commit events. Run Pint, PHPStan at maximum strictness, Composer validation, dependency analysis, generated-type checks, and distribution validation.

Configuration keys must have runtime behavior and tests. Public contract changes require changelog, README, skill, and upgrade updates.
